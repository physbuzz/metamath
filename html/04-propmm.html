Introduction

Now that we're set on the intricacies of Metamath, sans disjoint variables and compressed proofs, I want to familiarize myself with classical logic and similar systems with Metamath as grounding. Towards the end of these notes, I also try to tackle a few more creative systems in Metamath.

Note: I'm not going to write down tutorial information about proof assistants here, but this is certainly the time to start using the built-in proof assistant, or Yamma or mmj2.

I also got a bit frustrated mid-chapter and doubted whether it was worth it to work on these problems, since things always expand to take up much more time than I think. Probably, it's good to work on these for no other reason than to be able to interact with the Metamath community.

4.0 Important Logic Notations and Citations

Okay, as someone independently studying things and from the rather biased and pigheaded view that I cannot take things as "proven" or "beyond folk-knowledge" until I've formalized them in Metamath, I run the risk of developing crazy terminology that doesn't agree with literature. So I have to make sure I get my citations right!

While on the surface in this section we're battling propositional calculus, underneath we're really battling fundamental notions of proof. To my understanding, the requirement of making things concrete makes things so difficult that we can't easily tackle them until we've got through a formalization of set theory and then some. And from there, use set theory to build up a model1 of a formal language, and then prove theorems in our Metamath + set.mm + model. That becomes our metatheorem, and the assertion that our model accurately describes the formal language could turn out to be a philosophically fraught question. There's some series of unproductive arguments to have here, something like, "that's just a model of a system, not the system itself" -> "yeah so is everything you've ever proved about it, there the model was parsed by your brain, here the model is parsed by Metamath." Well, it will be nice to see how these statements age once I learn what they actually mean anyways--"actually" = "as formalized in mm" of course :)

4.0.1 Hilbert-type inference rules

TODO: use the word "axiom scheme" where appropriate. Buss is particularly precise about this.

Okay, right, formalization. For the notation most useful to us, I'll use three sources:

Source 1. The course notes A Hilbert Type Deductive System for Sentential Logic, Completeness and Compactness (Gaifman 2002). These are wonderful, just 9pgs and cover some results on satisfiability of the axioms of sentential (propositional) logic. Not at the level we can formalize yet in these notes, I'm pretty sure. The definitions are very direct: inference rule, conclusion, and premises. In Gaifman's notes, the inference rule of modus ponens is written as:

$$\frac{\alpha\to\beta,\;\alpha}{\beta}$$𝛼→𝛽,𝛼𝛽

Gaifman defines a Hilbert-type deductive system as follows. We won't follow it exactly, because we want to keep "wff" out of our definition:

A (Hilbert type) deductive system is a system consisting of a language and of (I) a set of wffs called axioms, and (II) a set of inference rules. An inference rule consists of (i) a list of wffs called the premises of the rule, (ii) a wff called the rule’s conclusion.

Source 2. The book Practical Foundations for Programming Languages (Harper 2012). Chapter one defines and proves alpha-equivalence, which FYI is a concept that appears in the top of peano.mm. But chapter 2 defines inference rules. Metamath's "typecode plus sequence of math symbols" is the analogue of a judgement here, and a Metamath assertion (proof or axiom) would be called a rule. In Harper's terminology, "a collection of rules forms an inductive definition of a judgement." Inference rules with no premises are called axioms, else are called proper rules (we won't be adopting this definition). For example, trees can be described by:

\begin{align*}\frac{}{\texttt{empty tree}} & &\frac{a_1\texttt{ tree}\quad a_2\texttt{ tree}}{\texttt{node}(a_1;a_2)\texttt{ tree}}\end{align*}𝚎𝚖𝚙𝚝𝚢 𝚝𝚛𝚎𝚎𝑎1 𝚝𝚛𝚎𝚎𝑎2 𝚝𝚛𝚎𝚎𝚗𝚘𝚍𝚎(𝑎1;𝑎2) 𝚝𝚛𝚎𝚎

which I would translate to Metamath as:

metamath
$c tree ( ; ) node empty $. $v a1 a2 $.
ta1 $f tree a1 $. ta2 $f tree a2 $.
tempty $a tree empty $.
tpair $a tree node ( a1 ; a2 ) $.

Source 3. Sam Buss's 2023 book/notes Introduction to Mathematical Logic also uses similar notation. He defines a proof system for propositional logic called PL, using "the symbol $\vdash A$⊢𝐴 to denote that $A$𝐴 has a propositional proof, $B_1,\ldots B_k\vdash A$𝐵1,…𝐵𝑘⊢𝐴 to denote that $A$𝐴 has a PL-proof from hypotheses $B_i.$𝐵𝑖." and "$\vDash$⊨ for tautological validity/implication." Sam Buss's book also has the wonderful footnote:

Hilbert-style systems are named after David Hilbert, one of the founding fathers of mathematical logic, as this style of proof was used in D. Hilbert and W. Ackermann’s 1928 book Grundzüge der theoretischen Logik (Foundations of Mathematical Logic). A system similar to a Hilbert-style system was already used by A.N. Whitehead and B. Russell in 1910 in their classic Principia Mathematica. Even earlier, G. Frege used a precursor to Hilbert-style proof systems in his 1879 Begriffsschrift. All three of these were landmark developments in establishing the modern study of mathematical logic.

To repeat myself, Buss writes modus ponens as:

$$\frac{A\qquad A\to B}{B}$$𝐴𝐴→𝐵𝐵

Okay, there's a little worry that I have here. Going by Gaifman's notes, interpreted liberally, we might call anything written in Metamath a Hilbert type system (or perhaps an extended Hilbert type system). But Megill is very careful to write in section 3.9.4, "The Metamath Proof Explorer (MPE) as defined in set.mm is fundamentally a Hilbert-style system," as opposed to a broad statement that Metamath systems in general are Hilbert-style systems.

I hemmed and hawed about the phrasing of this for too long; it seems like "Hilbert-style" is something to split hairs about. This is especially troublesome because all the logic texts I read--except for set.mm of course-- have the correctness of all of their definitions and terminology checked solely by the squishy lump of grey matter sitting on top of mathematicians' shoulders. As such, from Gaifman's definition, even though I argue we can translate one-to-one from the Hilbert style rules to $a and $p statements, we should sometimes take care not to say "the logic we're representing is Hilbert-style" if it represents a vastly different logic. For example, if I make a novel Metamath database using some kind of trick to represent type theoretic or sequent calculus constructions, then the Metamath proof mechanism is still "Hilbert-style" but the garbage I'm representing and so too the database and style of proof shouldn't be said to be "Hilbert-style."

4.0.2 Inference rules for us

For these notes, we'll write rules along with their typecode and label where possible. Two examples from set.mm are ax-mp and TODO (this sentence trails off)

$$\frac{\vdash \varphi\quad\vdash(\varphi\to \psi)}{\vdash \psi}\quad\texttt{ax-mp}$$⊢𝜑⊢(𝜑→𝜓)⊢𝜓𝚊𝚡-𝚖𝚙

and the more complicated syl

$$\frac{\vdash(\psi\to \varphi)\qquad\vdash(\varphi\to \chi)}{\vdash(\psi\to \chi)}\quad\texttt{syl}.$$⊢(𝜓→𝜑)⊢(𝜑→𝜒)⊢(𝜓→𝜒)𝚜𝚢𝚕.

While ax-mp is an axiom, syl is (in Harper's terminology) a derived rule, or in our terminology a theorem. It should be noted that ax-mp also requires premises $\texttt{wff }\varphi$𝚠𝚏𝚏 𝜑 and $\texttt{wff }\psi,$𝚠𝚏𝚏 𝜓, but we omit them for brevity.

An important convention for working in set.mm is that for practical purposes, a given theorem may come in inference form, deduction form, and closed form. Modus ponens has deduction form mpd

$$\frac{\vdash \varphi\to \psi\quad\vdash(\varphi\to (\psi\to \chi))}{\vdash (\varphi\to\chi)}\quad\texttt{mpd}$$⊢𝜑→𝜓⊢(𝜑→(𝜓→𝜒))⊢(𝜑→𝜒)𝚖𝚙𝚍

and closed form pm2.27

$$\frac{}{\vdash \varphi\to((\varphi\to\psi)\to\psi)}\quad\texttt{pm2.27}$$⊢𝜑→((𝜑→𝜓)→𝜓)𝚙𝚖𝟸.𝟸𝟽

4.1 Propositional calculus in set.mm

Let's start by building up some of the basic theorems and machinery of set.mm. We'll pick apart and cannibalize the usual set proof database and build up our own as a series of interdependent exercises. The problems are doable just using the metamath.exe proof assistant, but it's also a good opportunity to learn Yamma or mmj2. I recommend reading bits of the Metamath Proof Explorer, and the theorem documentation at https://us.metamath.org/mpeuni/<label>.html.

I also wrote a little cheatsheet at TODO URL, which you can use to keep a checklist or to remember different theorems we proved. The goal is to get the idea of how theorems are proved and how they're used in different forms, certainly not to memorize or to become a total expert at propositional logic.

The proof database we'll start with is:

metamath
$c wff |- -> -. ( ) $.
$v ph ps ch th ta $.
wph $f wff ph $.
wps $f wff ps $.
wch $f wff ch $.
wth $f wff th $.
wta $f wff ta $.
wn $a wff -. ph $.
wi $a wff ( ph -> ps ) $.
${
  min $e |- ph $.
  maj $e |- ( ph -> ps ) $.
  ax-mp $a |- ps $.
$}
ax-1 $a |- ( ph -> ( ps -> ph ) ) $.
ax-2 $a |- ( ( ph -> ( ps -> ch ) ) ->
             ( ( ph -> ps ) -> ( ph -> ch ) ) ) $.
ax-3 $a |- ( ( -. ph -> -. ps ) -> ( ps -> ph ) ) $.

Also note, metamath proof assistant commands:

  • assign n label, delete all, prove label, save new_proof, show new_proof/all/lemmon, improve all should be familiar.
  • save new_proof and write source to save and modify your target file (eg. myset.mm)
  • match step n (or match all) is super useful to list available unifications.

4.1.1 Implication: first proofs and useful derived rules

To start, here's some basic theorems: a1i, a2i, mpd, syl, and id.

Note that here we start seeing some of the conventions of set.mm, where the suffix i generally stands for inference form, suffix d stands for deduction form, and no suffix generally stands for closed form. This is discussed various places in the proof explorer such as here and in the book html page or pdf page. The proof explorer pages of these are really good, tons of info.

NB: For sections 4.1.1 to 4.1.3, you only need axioms ax-1, ax-2, and ax-mp, making these theorems intuitionistic.

metamath
$( Add an antecedent $)
${
  a1i.1 $e |- ph $.
  a1i $p |- ( ps -> ph ) $= ? $.
$}

$( Distribute an antecedent $)
${
  a2i.1 $e |- ( ph -> ( ps -> ch ) ) $.
  a2i $p |- ( ( ph -> ps ) -> ( ph -> ch ) ) $= ? $.
$}

$( Modus ponens under shared antecedent. AKA modus ponens in deductive form.
   You'll use it constantly! 
   Try proving this using a2i $)
${
  mpd.1 $e |- ( ph -> ps ) $.
  mpd.2 $e |- ( ph -> ( ps -> ch ) ) $.
  mpd $p |- ( ph -> ch ) $= ? $.
$}

$( syllogism, or "hypothetical syllogism" $)
${
  syl.1 $e |- ( ph -> ps ) $.
  syl.2 $e |- ( ps -> ch ) $.
  syl $p |- ( ph -> ch ) $= ? $.
$}

$( A standard "first proof" in Hilbert-style textbooks. It's lemma 1.8
   of Mendelson and "our first proof" in Hirst & Hirst.  $)
id $p |- ( ph -> ph ) $= ? $.

Hints and my answers

Hints2.

  • a1i follows from modus ponens and an axiom.
  • a2i follows from modus ponens and an axiom.
  • mpd can be proved using a2i in its proof.
  • A short proof of syl doesn't use any axioms explicitly, only the theorems we proved.
  • One theorem, then two axioms.

I solved this without using the hints, and got the following rather long proofs.

metamath
${  a1i.1 $e |- ph $.
  a1i $p |- ( ps -> ph ) $=
    wph wps wph wi a1i.1 wph wps ax-1 ax-mp $. $}
${ a2i.1 $e |- ( ph -> ( ps -> ch ) ) $.
   a2i $p |- ( ( ph -> ps ) -> ( ph -> ch ) ) $=
    wph wps wch wi wi wph wps wi wph wch wi wi a2i.1 wph wps wch ax-2 ax-mp $. $}
${ mpd.1 $e |- ( ph -> ps ) $.
   mpd.2 $e |- ( ph -> ( ps -> ch ) ) $.
   mpd $p |- ( ph -> ch ) $=
    wph wps wi wph wch wi mpd.1 wph wps wch wi wi wph wps wi wph wch wi wi
    mpd.2 wph wps wch ax-2 ax-mp ax-mp $. $}
${ syl.1 $e |- ( ph -> ps ) $.
   syl.2 $e |- ( ps -> ch ) $.
   syl $p |- ( ph -> ch ) $=
    wph wps wi wph wch wi syl.1 wph wps wch wi wi wph wps wi wph wch wi wi wps
    wch wi wph wps wch wi wi syl.2 wps wch wi wph ax-1 ax-mp wph wps wch ax-2
    ax-mp ax-mp $. $}
id $p |- ( ph -> ph ) $=
  wph wph wph wi wph wph wph ax-1 wph wph wph wi ax-1 mpd $.

The proof explorer also has idALT, which proves id without mpd and which proves the same statement directly from the axioms, as well as giving some nice exposition.

After the hints, we can simplify the proofs of mpd and syl to be much shorter:

metamath
mpd $p |- ( ph -> ch ) $=
  wph wps wi wph wch wi mpd.1 wph wps wch mpd.2 a2i ax-mp $.
syl $p |- ( ph -> ch ) $=
  wph wps wch syl.1 wps wch wi wph syl.2 a1i mpd $.

4.1.2 More advanced implications

Prove pm2.43i, a1d, a2d, sylcom, com12, pm2.27, and imim2i.

These start to get a little more interesting.

metamath
$( Remove repeated antecedent. AKA contraction.
   This is theorem 2.43 of Principia Mathematica. $)
${
  pm2.43i.1 $e |- ( ph -> ( ph -> ps ) ) $.
  pm2.43i $p |- ( ph -> ps ) $= ? $.
$}

$( The deduction form of a1i. A deduction form puts the same 
   antecedent `ph ->` in front of every hypothesis and conclusion. $)
${
  a1d.1 $e |- ( ph -> ps ) $.
  a1d $p |- ( ph -> ( ch -> ps ) ) $= ? $.
$}

$( The deduction form of a2i. $)
${
  a2d.1 $e |- ( ph -> ( ps -> ( ch -> th ) ) ) $.
  a2d $p |- ( ph -> ( ( ps -> ch ) -> ( ps -> th ) ) ) $= ? $.
$}

$( Syllogism inference with commutation of antecedents. $)
${
  sylcom.1 $e |- ( ph -> ( ps -> ch ) ) $.
  sylcom.2 $e |- ( ps -> ( ch -> th ) ) $.
  sylcom $p |- ( ph -> ( ps -> th ) ) $= ? $.
$}

$(  Inference that commutes antecedents in an implication. $)
${
  com12.1 $e |- ( ph -> ( ps -> ch ) ) $.
  com12 $p |- ( ps -> ( ph -> ch ) ) $= ? $.
$}

$( "Closed form" of modus ponens $)
pm2.27 $p |- ( ph -> ( ( ph -> ps ) -> ps ) ) $= ? $.

$( implication of implications $)
${
  imim2i.1 $e |- ( ph -> ps ) $.
  imim2i $p |- ( ( ch -> ph ) -> ( ch -> ps ) ) $= ? $.
$}

Hints and my answers

  • For pm2.43i, ax-mp isn't quite the right tool.
  • a1d and a2d use syllogism.
  • For sylcom, I find this at least a bit clever: use syl with sylcom.1 as its first premise. If you're still stuck, use match step n to find the other theorem you have to use.
  • com12 basically yields to 1 theorem, so match step is your friend.
  • For pm2.27, use com12. Look carefully at the remaining goal before doing any more work!
  • For imim2i, use a2i. The remaining goal differs from the hypothesis by just one antecedent.

My solns:

metamath
pm2.43i $p |- ( ph -> ps ) $=
    wph wph wps wph id pm2.43i.1 mpd $.

a1d $p |- ( ph -> ( ch -> ps ) ) $=
    wph wps wch wps wi a1d.1 wps wch wps wi wi wph wps wch ax-1 a1i mpd $.

$( Rewrite after realizing to use syl: $)
a1d $p |- ( ph -> ( ch -> ps ) ) $=
  wph wps wch wps wi a1d.1 wps wch ax-1 syl $.

a2d $p |- ( ph -> ( ( ps -> ch ) -> ( ps -> th ) ) ) $=
  wph wps wch wth wi wi wps wch wi wps wth wi wi a2d.1 wps wch wth ax-2 syl
  $.

sylcom $p |- ( ph -> ( ps -> th ) ) $=
  wph wps wch wi wps wth wi sylcom.1 wph wps wch wth wps wch wth wi wi wph
  sylcom.2 a1i a2d mpd $.
$(improved proof: $)
sylcom $p |- ( ph -> ( ps -> th ) ) $=
  wph wps wch wi wps wth wi sylcom.1 wps wch wth sylcom.2 a2i syl $.

com12 $p |- ( ps -> ( ph -> ch ) ) $=
  wps wph wps wch wps wph ax-1 com12.1 sylcom $.

pm2.27 $p |- ( ph -> ( ( ph -> ps ) -> ps ) ) $=
  wph wps wi wph wps wph wps wps wps wps wi wph wps id a1i a2i com12 $.

imim2i $p |- ( ( ch -> ph ) -> ( ch -> ps ) ) $=
  wch wph wps wph wps wi wch imim2i.1 a1i a2i $.

4.1.3 More propositional calculus

Write proofs introducing more propositional calculus tools, mpdd, syld, imim1i, imim2, imim1, pm2.43, and pm2.04.

I had a tough time on this section, and only read later that the Metamath proof explorer asserts that "once you have an assertion in deduction form, you can easily convert it to inference form or closed form", with instructions how! You still only need ax-1, ax-2, and ax-mp btw.

metamath
$( Deduction form of mpd $)
${
  mpdd.1 $e |- ( ph -> ( ps -> ch ) ) $.
  mpdd.2 $e |- ( ph -> ( ps -> ( ch -> th ) ) ) $.
  mpdd $p |- ( ph -> ( ps -> th ) ) $= ? $.
$}

$( Deduction form of syl $)
${
  syld.1 $e |- ( ph -> ( ps -> ch ) ) $.
  syld.2 $e |- ( ph -> ( ch -> th ) ) $.
  syld $p |- ( ph -> ( ps -> th ) ) $= ? $.
$}

$( Note: This can be viewed as a syllogism but with the hypothesis syl.2
   "discharged" and turned into an antecedent. $)
${
  imim1i.1 $e |- ( ph -> ps ) $.
  imim1i $p |- ( ( ps -> ch ) -> ( ph -> ch ) ) $= ? $.
$}

$( The following closed forms of theorems we've already proved do the same
   trick. We discharge a hypothesis. $)
imim2 $p |- ( ( ph -> ps ) -> ( ( ch -> ph ) -> ( ch -> ps ) ) ) $= ? $.

imim1 $p |- ( ( ph -> ps ) -> ( ( ps -> ch ) -> ( ph -> ch ) ) ) $= ? $.

pm2.43 $p |- ( ( ph -> ( ph -> ps ) ) -> ( ph -> ps ) ) $= ? $.

pm2.04 $p |- ( ( ph -> ( ps -> ch ) ) -> ( ps -> ( ph -> ch ) ) ) $= ? $.

Hints and my answers

  • For mpdd, use mpd, keeping ph as the shared antecedent. Compare the remaining premise with the deduction form of a2i.
  • For syld, try mpdd. One hypothesis already fits; the other needs an extra antecedent inside ph ->.
  • For imim1i, use syld with ( ps -> ch ) as the shared antecedent. Remember that a whole implication can take the place of a wff variable.
  • For imim2, use syl. Look for an intermediate formula that lets ax-2 supply the second premise.
  • For imim1, try commuting the outer two antecedents. The remaining goal is an instance of an earlier theorem, with the variables shuffled around.
  • pm2.43 has the form of a2i's conclusion, with a compound wff in place of one variable.
  • For pm2.04, use syl with ax-2 as its first premise. The other premise keeps ( ph -> ch ) as its consequent; look for an inference that changes an antecedent.

4.1.4 Negation and classical propositional calculus

Warning

I got stuck here at pm2.21 and decided I didn't want to make a cheat sheet of logic terms and get deep into the weeds. I might get back to it later as a way to practice proof assistants. It's very fun but just not somewhere I want to spend time developing expertise.

(So the hints and stuff, or that these are good problems, haven't been thoroughly checked!)

Now we introduce ax-3, meaning we're in the realm of classical logic. Up until now, our theorems have been acceptable intuitionistic theorems. Prove the basic theorems con4i, con4d, pm2.21i, pm2.24ii, pm2.21d, pm2.21, pm2.24, and pm2.18.

metamath
$( Inference form of axiom 3. "Con" is short for "contraposition" $)
${
  con4i.1 $e |- ( -. ph -> -. ps ) $.
  con4i $p |- ( ps -> ph ) $= ? $.
$}

$( Deduction form of axiom 3. $)
${
  con4d.1 $e |- ( ph -> ( -. ps -> -. ch ) ) $.
  con4d $p |- ( ph -> ( ch -> ps ) ) $= ? $.
$}

$( Principle of explosion: A contradiction implies anything. $)
${
  pm2.21i.1 $e |- -. ph $.
  pm2.21i $p |- ( ph -> ps ) $= ? $.
$}
$( Also principle of explosion. $)
${
  pm2.24ii.1 $e |- ph $.
  pm2.24ii.2 $e |- -. ph $.
  pm2.24ii $p |- ps $= ? $.
$}
$( deduction form of explosion $)
${
  pm2.21d.1 $e |- ( ph -> -. ps ) $.
  pm2.21d $p |- ( ph -> ( ps -> ch ) ) $= ? $.
$}

$( closed forms of explosion $)
pm2.21 $p |- ( -. ph -> ( ph -> ps ) ) $= ? $.
pm2.24 $p |- ( ph -> ( -. ph -> ps ) ) $= ? $.

$( Clavius law: if a formula follows from its own negation, then it's true. $)
pm2.18 $p |- ( ( -. ph -> ph ) -> ph ) $= ? $.

Hints and my answers

  • con4i follows from modus ponens and an axiom.
  • For con4d, use syl with the given hypothesis as its first premise.
  • For pm2.21i, use con4i. The remaining goal just adds an antecedent to the hypothesis.
  • For pm2.24ii, use ax-mp with ph as its first premise. The other hypothesis lets you use the explosion rule we just proved.
  • For pm2.21d, use con4d. Keep ph as the shared antecedent while adding an antecedent inside it.
  • For pm2.21, use pm2.21d. Choose the shared antecedent to match the goal, then look carefully at the remaining premise.
  • For pm2.24, try commuting the two antecedents.
  • For pm2.18, use pm2.43i with ( -. ph -> ph ) as a single wff. The remaining goal fits con4d; keep that same shared antecedent as you work backwards.

4.1.5 Double negation and classical proof rules

4.1.7 Carew Meredith's sole axiom for propositional calculus

Back to implication and negation. We started with three logical axioms and modus ponens. Could we replace those three axioms with just one?

Meredith's axiom does this. It is a fairly intimidating string, but it uses the same formula syntax we already know how to parse:

metamath
meredith $a |- ( ( ( ( ( ph -> ps ) -> ( -. ch -> -. th ) ) -> ch ) -> ta ) ->
                ( ( ta -> ph ) -> ( th -> ph ) ) ) $.

Use meredith.mm for these exercises. Its logical axioms are meredith and ax-mp; it also has the familiar syntax declarations. The supporting lemmas are supplied as $p statements. They eventually depend on merlem1, which is the first blank to fill in.

We won't try to rediscover the whole development. That would be a very different exercise! The task here is to assemble some carefully chosen instances with modus ponens. The notation in the hints abbreviates formulas; it doesn't add new symbols to the database.

A first lemma

Prove merlem1:

metamath
merlem1 $p |- ( ( ( ch -> ( -. ph -> ps ) ) -> ta ) -> ( ph -> ta ) ) $= ? $.

Here is a more guided hint than usual. Write M(a,b,c,d,e) for the Meredith axiom with those five formulas substituted for ph, ps, ch, th, and ta. For this paragraph, rename the variables of the target to a,b,c,t, and put

text
N = (¬a → b)
X = (¬t → ¬c)
Z = ((t → ¬a) → (¬N → ¬a))

The three instances you need are

text
M(¬a, b, X, ¬N, t)
M(N, (¬X → ¬¬N), t, c, Z)
M(t, ¬a, N, a, (c → N))

Start with ax-mp at the target, and work out which instance can supply the implication. The remaining goal needs one more use of modus ponens. Writing the three instances out is probably less painful than trying to hold them in your head.

Recovering three familiar statements

Once merlem1 is filled in, the supplied proofs establish the remaining merlem lemmas. Use them to prove the following, in the order luk-3, luk-2, then luk-1:

These are the Łukasiewicz axioms used in this development. We recognize their statements as explosion, Clavius law, and a closed form of syllogism. Here they are theorems derived from Meredith's axiom, so borrowing their section 4.1 proofs would defeat the point.

Thoughts on inference, deduction, closed

NB: Like always this is a beginner's question from a beginner's perspective.

Once we start proving things about inference, deduction, and closed forms, we're pretty naturally confronted with the idea of a metatheorem. With a bit more elbow grease, we know--in our heart of hearts--that an algorithm relying on proof tables exists to determine all theorems like this. Or, we know in our heart of hearts that we can take an essential hypothesis and discharge it to get the closed form of the theorem.

The existence of a proof should clearly be called a metatheorem, since we would like to eventually formalize it and it's a theorem about theorems. And we clearly do not yet have the tools to formalize, "If we have a proof of propositional logic statements of the form ${ foo.1 $e |- ch $. foo $p |- ps $= ? $. $} then we also have a proof of the form $p |- ch -> ps $." I can live with that so long as we get to it later.

However, there's another way to think about this: If I wanted to reason about performing deductions, I might, instead of writing ${ foo.1 $e |- ch $. foo $p |- ps $= ? $. $}, write $p |- ch => ps $., which I endow with the intention of meaning "with chi as an essential axiom, I deduce psi through Hilbert-style reasoning." And then, if I build up enough axioms of my scheme that accurately captures things, I eventually might wind up at $p |- => ch -> ps $., meaning, "with no filled essential hypothesis in my Hilbert-style scheme, chi implies psi."

The deduction theorem is then something like

${ foo.1 $e |- ch => ps $. foo $p |- => ch -> ps $= ? $. $}

But we're left with a philosophical issue: is my intention of what the => symbol means properly matched by the extra axioms I have to come up with?

And you have to understand where I'm coming from: the "non-mathematician's quest for truth" is troublesome because if you say, "study model theory" or whatnot, then fine, but we'll phrase model theory in terms of Metamath so we're really still in the weeds.

I used de Bruijn's criterion as a way to get out of ground 0 of these troublesome issues; do we have to apply such a criterion again? Say => is endowed with meaning by a description of Metamath we write in Metamath. Then the simple, inspectability of the description of this Metamath interpreter is important, and there remains a bit of philosophical faith in the veracity of our meta-theorem.

4.2.3 Higher Order Logic hol.mm

Warning

In section 4.1, an assumption was usually a separate $e statement. The higher-order logic database hol.mm also has statements of the form

text
|- R |= S

Read this as "under assumption R, we have S." The assumption is now part of the expression! R and S have type term, and ( S , T ) combines two assumptions. The |= symbol separates the context from the conclusion. It is another declared constant, not an instruction to the Metamath program.

Here is enough of the language to try a first exercise in its own file. These are the context-combination and transitivity rules from hol.mm, together with the syntax they need.

metamath

$v A B R S T $.
ta $f term A $.
tb $f term B $.
tr $f term R $.
ts $f term S $.
tt $f term T $.
kct $a term ( A , B ) $.

${
  ax-syl.1 $e |- R |= S $.
  ax-syl.2 $e |- S |= T $.
  ax-syl $a |- R |= T $.
$}
${
  ax-jca.1 $e |- R |= S $.
  ax-jca.2 $e |- R |= T $.
  ax-jca $a |- R |= ( S , T ) $.
$}

${
  syl2anc.1 $e |- R |= S $.
  syl2anc.2 $e |- R |= T $.
  syl2anc.3 $e |- ( S , T ) |= A $.
  syl2anc $p |- R |= A $= ? $.
$}

Prove syl2anc. Its first two hypotheses get us S and T in context R; its third knows how to get A from their combination. We still have to express that little argument as substitutions and proof steps.

The next exercise needs more of the database. Use hol.mm, which supplies the supporting theorems and leaves syl2anc and mpd blank. Some of the supplied proofs are compressed; you can use their statements without unpacking their proofs. For example, start with:

text
read hol.mm
prove syl2anc

Then try mpd:

metamath
${
  mp.1 $e |- T : bool $.
  mp.2 $e |- R |= S $.
  mp.3 $e |- R |= [ S ==> T ] $.
  mpd $p |- R |= T $= ? $.
$}

There are two different kinds of type information here. $f term T says that T is a syntactic term. The hypothesis |- T : bool is an assertion about that term: it has Boolean type. On the proof explorer, bool is displayed as ∗. Use bool in the source file.

[ S ==> T ] is implication, while [ S /\ T ] is Boolean conjunction. The square brackets are part of the syntax. Context conjunction ( S , T ) and Boolean conjunction [ S /\ T ] look related, but they are different strings, so we need a theorem to pass between them.

The interesting bit is that modus ponens is a theorem here. Implication has been defined using equality and conjunction. One of the primitive rules, ax-eqmp, transports an assertion along an equality. The derived rules mpbi and mpbir do that with the bracket notation, in opposite directions.

These are the useful tools to inspect before starting:

Label What to look for
imval Relates [ S ==> T ] to [ [ S /\ T ] = S ].
a1i Moves a theorem from the true context T. into a Boolean context R.
mpbi, mpbir Replace a term by an equal term inside a fixed context.
dfan2 Relates [ S /\ T ] to ( S , T ).
simprd Extracts the right member of a context conjunction.
ax-cb1, ax-cb2 Extract Boolean type assertions about the context and conclusion.

The names overlap with set.mm, but read their statements again. In particular, the hypotheses required by a1i are different. This is a good place to let the proof assistant show us exactly which strings are still missing.

Hints and my answers

  • For syl2anc, use ax-syl with the third hypothesis as its second premise.
  • For mpd, use simprd. The remaining goal needs a context conjunction; dfan2 will let you work back to a Boolean conjunction.
  • A second hint for mpd: to obtain the Boolean conjunction from the hypothesis R |= S, look at mpbir. Its equality premise comes from the implication hypothesis and imval. Keep track of the context when using that theorem.
