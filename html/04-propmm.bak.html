4 Studying Propositional Calculus with Metamath

Now that we're set on the intricacies of Metamath, sans disjoint variables and compressed proofs, I want to familiarize myself with logic with Metamath as grounding. This includes:

  • The theorems and conventions in set.mm, up to predicate calculus.
  • Other "propositional-like" proof databases.
  • Proving substantive statements with a proof assistant (built-in proof assistant, or Yamma, or mmj2).

So, we'll work through basic formal systems, as far as we can get until our patience runs out, or we can no longer avoid disjoint variables.

04.1 Propositional calculus in set.mm

Let's start by building up some of the basic theorems and machinery of set.mm. We'll pick apart and cannibalize the usual set proof database, but you still might find it useful to visit the Metamath Proof Explorer, page 1 of 513, which is good reading.

This section is formulated as a series of interdependent exercises which you can use to build up some pieces of set.mm, preferably in the start of a new file like myset.mm. There are hints and solutions, and you can also find the theorem in set.mm or view it by editing the url https://us.metamath.org/mpeuni/<label>.html. There's usually cool stuff to see in the metamath set explorer.

The foundation we'll use is:

metamath
$c wff |- -> -. ( ) $.
$v ph ps ch th ta $.
wph $f wff ph $.
wps $f wff ps $.
wch $f wff ch $.
wth $f wff th $.
wta $f wff ta $.
wn $a wff -. ph $.
wi $a wff ( ph -> ps ) $.
${
  min $e |- ph $.
  maj $e |- ( ph -> ps ) $.
  ax-mp $a |- ps $.
$}
ax-1 $a |- ( ph -> ( ps -> ph ) ) $.
ax-2 $a |- ( ( ph -> ( ps -> ch ) ) ->
             ( ( ph -> ps ) -> ( ph -> ch ) ) ) $.
ax-3 $a |- ( ( -. ph -> -. ps ) -> ( ps -> ph ) ) $.

Also note, metamath proof assistant commands:

  • assign n label, delete all, prove label, save new_proof, show new_proof/all/lemmon, improve all should be familiar.
  • save new_proof and write source to save and modify your target file (eg. myset.mm)
  • match term [proof step] is super useful to list available unifications.

4.1.1 Implication: first proofs and useful derived rules

To start, here's some basic theorems: a1i, a2i, mpd, syl, and id.

Note that here we start seeing some of the conventions of set.mm, where the suffix i generally stands for inference form, suffix d stands for deduction form, and no suffix generally stands for closed form. This is discussed various places in the proof explorer such as here and in the book html page or pdf page. The proof explorer pages of these are really good, tons of info.

NB: For sections 4.1.1 to 4.1.3, you only need axioms ax-1, ax-2, and ax-mp, making these theorems intuitionistic.

metamath
$( Add an antecedent $)
${
  a1i.1 $e |- ph $.
  a1i $p |- ( ps -> ph ) $= ? $.
$}

$( Distribute an antecedent $)
${
  a2i.1 $e |- ( ph -> ( ps -> ch ) ) $.
  a2i $p |- ( ( ph -> ps ) -> ( ph -> ch ) ) $= ? $.
$}

$( Modus ponens under shared antecedent. AKA modus ponens in deductive form.
   You'll use it constantly! 
   Try proving this using a2i $)
${
  mpd.1 $e |- ( ph -> ps ) $.
  mpd.2 $e |- ( ph -> ( ps -> ch ) ) $.
  mpd $p |- ( ph -> ch ) $= ? $.
$}

$( syllogism, or "hypothetical syllogism" $)
${
  syl.1 $e |- ( ph -> ps ) $.
  syl.2 $e |- ( ps -> ch ) $.
  syl $p |- ( ph -> ch ) $= ? $.
$}

$( A standard "first proof" in Hilbert-style textbooks. It's lemma 1.8
   of Mendelson and "our first proof" in Hirst & Hirst.  $)
id $p |- ( ph -> ph ) $= ? $.

Hints and my answers

Hints1.

  • a1i follows from modus ponens and an axiom.
  • a2i follows from modus ponens and an axiom.
  • mpd can be proved using a2i in its proof.
  • A short proof of syl doesn't use any axioms explicitly, only the theorems we proved.
  • One theorem, then two axioms.

I solved this without using the hints, and got the following rather long proofs.

metamath
${  a1i.1 $e |- ph $.
  a1i $p |- ( ps -> ph ) $=
    wph wps wph wi a1i.1 wph wps ax-1 ax-mp $. $}
${ a2i.1 $e |- ( ph -> ( ps -> ch ) ) $.
   a2i $p |- ( ( ph -> ps ) -> ( ph -> ch ) ) $=
    wph wps wch wi wi wph wps wi wph wch wi wi a2i.1 wph wps wch ax-2 ax-mp $. $}
${ mpd.1 $e |- ( ph -> ps ) $.
   mpd.2 $e |- ( ph -> ( ps -> ch ) ) $.
   mpd $p |- ( ph -> ch ) $=
    wph wps wi wph wch wi mpd.1 wph wps wch wi wi wph wps wi wph wch wi wi
    mpd.2 wph wps wch ax-2 ax-mp ax-mp $. $}
${ syl.1 $e |- ( ph -> ps ) $.
   syl.2 $e |- ( ps -> ch ) $.
   syl $p |- ( ph -> ch ) $=
    wph wps wi wph wch wi syl.1 wph wps wch wi wi wph wps wi wph wch wi wi wps
    wch wi wph wps wch wi wi syl.2 wps wch wi wph ax-1 ax-mp wph wps wch ax-2
    ax-mp ax-mp $. $}
id $p |- ( ph -> ph ) $=
  wph wph wph wi wph wph wph ax-1 wph wph wph wi ax-1 mpd $.

The proof explorer also has idALT, which proves id without mpd and which proves the same statement directly from the axioms, as well as giving some nice exposition.

After the hints, we can simplify the proofs of mpd and syl to be much shorter:

metamath
mpd $p |- ( ph -> ch ) $=
  wph wps wi wph wch wi mpd.1 wph wps wch mpd.2 a2i ax-mp $.
syl $p |- ( ph -> ch ) $=
  wph wps wch syl.1 wps wch wi wph syl.2 a1i mpd $.

4.1.2 More advanced implications

Prove pm2.43i, a1d, a2d, sylcom, com12, pm2.27, and imim2i.

These start to get a little more interesting.

metamath
$( Remove repeated antecedent. AKA contraction.
   This is theorem 2.43 of Principia Mathematica. $)
${
  pm2.43i.1 $e |- ( ph -> ( ph -> ps ) ) $.
  pm2.43i $p |- ( ph -> ps ) $= ? $.
$}

$( The deduction form of a1i. A deduction form puts the same 
   antecedent `ph ->` in front of every hypothesis and conclusion. $)
${
  a1d.1 $e |- ( ph -> ps ) $.
  a1d $p |- ( ph -> ( ch -> ps ) ) $= ? $.
$}

$( The deduction form of a2i. $)
${
  a2d.1 $e |- ( ph -> ( ps -> ( ch -> th ) ) ) $.
  a2d $p |- ( ph -> ( ( ps -> ch ) -> ( ps -> th ) ) ) $= ? $.
$}

$( Syllogism inference with commutation of antecedents. $)
${
  sylcom.1 $e |- ( ph -> ( ps -> ch ) ) $.
  sylcom.2 $e |- ( ps -> ( ch -> th ) ) $.
  sylcom $p |- ( ph -> ( ps -> th ) ) $= ? $.
$}

$(  Inference that commutes antecedents in an implication. $)
${
  com12.1 $e |- ( ph -> ( ps -> ch ) ) $.
  com12 $p |- ( ps -> ( ph -> ch ) ) $= ? $.
$}

$( "Closed form" of modus ponens $)
pm2.27 $p |- ( ph -> ( ( ph -> ps ) -> ps ) ) $= ? $.

$( implication of implications $)
${
  imim2i.1 $e |- ( ph -> ps ) $.
  imim2i $p |- ( ( ch -> ph ) -> ( ch -> ps ) ) $= ? $.
$}

Out of place scratchwork

The differences between the inference form and the deduction form seems like there's a metatheorem here. Two ways of phrasing this:

Number one, a statement something like "If we have a proof of propositional logic statements of the form ${ foo.1 $e |- ch $. foo $p |- ps $= ? $. $} then we also have a proof of the form $p |- ch -> ps $. This is like we have assumed chi, proved psi, then discharged the assumption of chi. Because it's a statement about the existence of a proof, it's a metatheorem.

However, there's another way to think about this, that was is that I suppose I have a theory, where I perform deductions, getting psi from chi. Now, I want to reason about those deductions, so I invent the double arrow symbol to mean "deduces". Now I start reasoning with statements in the form $p |- ch => ps $., but someone comes along and tells me, "oh yeah, that's actually not enough to make a statement about deduction, you need a metatheorem." But I literally invented the arrow for that purpose! WTF? Is there some philosophical leap to make here, or are we confronted yet again with the notion of, "what if my => properties and axioms that I define, don't fully encompass the consequences of my original form of deduction [reaching statements by Metamath replacement rules]?" just like we were confronted at the beginning of our metamath journey, "what if the proof checking system that I'm programming has bugs or inadequacies in it, and doesn't capture the colloquial idea of proof?"

Hints and my answers

  • For pm2.43i, ax-mp isn't quite the right tool.
  • a1d and a2d use syllogism.
  • For sylcom, I find this at least a bit clever: use syl with sylcom.1 as its first premise. If you're still stuck, use which step n to find the other theorem you have to use.
  • com12 basically yields to 1 theorem, so which is your friend.
  • For pm2.27, use com12. Look carefully at the remaining goal before doing any more work!
  • For imim2i, use a2i. The remaining goal differs from the hypothesis by just one antecedent.

My solns:

metamath
pm2.43i $p |- ( ph -> ps ) $=
    wph wph wps wph id pm2.43i.1 mpd $.

a1d $p |- ( ph -> ( ch -> ps ) ) $=
    wph wps wch wps wi a1d.1 wps wch wps wi wi wph wps wch ax-1 a1i mpd $.

$( Rewrite after realizing to use syl: $)
a1d $p |- ( ph -> ( ch -> ps ) ) $=
  wph wps wch wps wi a1d.1 wps wch ax-1 syl $.

a2d $p |- ( ph -> ( ( ps -> ch ) -> ( ps -> th ) ) ) $=
  wph wps wch wth wi wi wps wch wi wps wth wi wi a2d.1 wps wch wth ax-2 syl
  $.

sylcom $p |- ( ph -> ( ps -> th ) ) $=
  wph wps wch wi wps wth wi sylcom.1 wph wps wch wth wps wch wth wi wi wph
  sylcom.2 a1i a2d mpd $.
$(improved proof: $)
sylcom $p |- ( ph -> ( ps -> th ) ) $=
  wph wps wch wi wps wth wi sylcom.1 wps wch wth sylcom.2 a2i syl $.

com12 $p |- ( ps -> ( ph -> ch ) ) $=
  wps wph wps wch wps wph ax-1 com12.1 sylcom $.

pm2.27 $p |- ( ph -> ( ( ph -> ps ) -> ps ) ) $=
  wph wps wi wph wps wph wps wps wps wps wi wph wps id a1i a2i com12 $.

imim2i $p |- ( ( ch -> ph ) -> ( ch -> ps ) ) $=
  wch wph wps wph wps wi wch imim2i.1 a1i a2i $.

4.1.3 More propositional calculus

Write proofs introducing more propositional calculus tools, mpdd, syld, imim1i, imim2, imim1, pm2.43, and pm2.04.

I had a tough time on this section, and only read later that the Metamath proof explorer asserts that "once you have an assertion in deduction form, you can easily convert it to inference form or closed form", with instructions how! You still only need ax-1, ax-2, and ax-mp btw.

metamath
$( Deduction form of mpd $)
${
  mpdd.1 $e |- ( ph -> ( ps -> ch ) ) $.
  mpdd.2 $e |- ( ph -> ( ps -> ( ch -> th ) ) ) $.
  mpdd $p |- ( ph -> ( ps -> th ) ) $= ? $.
$}

$( Deduction form of syl $)
${
  syld.1 $e |- ( ph -> ( ps -> ch ) ) $.
  syld.2 $e |- ( ph -> ( ch -> th ) ) $.
  syld $p |- ( ph -> ( ps -> th ) ) $= ? $.
$}

$( Note: This can be viewed as a syllogism but with the hypothesis syl.2
   "discharged" and turned into an antecedent. $)
${
  imim1i.1 $e |- ( ph -> ps ) $.
  imim1i $p |- ( ( ps -> ch ) -> ( ph -> ch ) ) $= ? $.
$}

$( The following closed forms of theorems we've already proved do the same
   trick. We discharge a hypothesis. $)
imim2 $p |- ( ( ph -> ps ) -> ( ( ch -> ph ) -> ( ch -> ps ) ) ) $= ? $.

imim1 $p |- ( ( ph -> ps ) -> ( ( ps -> ch ) -> ( ph -> ch ) ) ) $= ? $.

pm2.43 $p |- ( ( ph -> ( ph -> ps ) ) -> ( ph -> ps ) ) $= ? $.

pm2.04 $p |- ( ( ph -> ( ps -> ch ) ) -> ( ps -> ( ph -> ch ) ) ) $= ? $.

Hints and my answers

  • For mpdd, use mpd, keeping ph as the shared antecedent. Compare the remaining premise with the deduction form of a2i.
  • For syld, try mpdd. One hypothesis already fits; the other needs an extra antecedent inside ph ->.
  • For imim1i, use syld with ( ps -> ch ) as the shared antecedent. Remember that a whole implication can take the place of a wff variable.
  • For imim2, use syl. Look for an intermediate formula that lets ax-2 supply the second premise.
  • For imim1, try commuting the outer two antecedents. The remaining goal is an instance of an earlier theorem, with the variables shuffled around.
  • pm2.43 has the form of a2i's conclusion, with a compound wff in place of one variable.
  • For pm2.04, use syl with ax-2 as its first premise. The other premise keeps ( ph -> ch ) as its consequent; look for an inference that changes an antecedent.

My answers. I didn't get pm2.04 without help, hah!

  wps wph wth wps wph wch wth wph wps wch syld.1 com12 syld.2 sylcom com12 $.
imim1i $p |- ( ( ps -> ch ) -> ( ph -> ch ) ) $=

  syld $.
imim2 $p |- ( ( ph -> ps ) -> ( ( ch -> ph ) -> ( ch -> ps ) ) ) $=

4.1.4 Negation and classical propositional calculus

Now we introduce ax-3, meaning we're in the realm of classical logic. Up until now, our theorems have been acceptable intuitionistic theorems. Prove the basic theorems con4i, con4d, pm2.21i, pm2.24ii, pm2.21d, pm2.21, pm2.24, and pm2.18.

metamath
$( Inference form of axiom 3. "Con" is short for "contraposition" $)
${
  con4i.1 $e |- ( -. ph -> -. ps ) $.
  con4i $p |- ( ps -> ph ) $= ? $.
$}

$( Deduction form of axiom 3. $)
${
  con4d.1 $e |- ( ph -> ( -. ps -> -. ch ) ) $.
  con4d $p |- ( ph -> ( ch -> ps ) ) $= ? $.
$}

$( Principle of explosion: A contradiction implies anything. $)
${
  pm2.21i.1 $e |- -. ph $.
  pm2.21i $p |- ( ph -> ps ) $= ? $.
$}
$( Also principle of explosion. $)
${
  pm2.24ii.1 $e |- ph $.
  pm2.24ii.2 $e |- -. ph $.
  pm2.24ii $p |- ps $= ? $.
$}
$( deduction form of explosion $)
${
  pm2.21d.1 $e |- ( ph -> -. ps ) $.
  pm2.21d $p |- ( ph -> ( ps -> ch ) ) $= ? $.
$}

$( closed forms of explosion $)
pm2.21 $p |- ( -. ph -> ( ph -> ps ) ) $= ? $.
pm2.24 $p |- ( ph -> ( -. ph -> ps ) ) $= ? $.

$( Clavius law: if a formula follows from its own negation, then it's true. $)
pm2.18 $p |- ( ( -. ph -> ph ) -> ph ) $= ? $.

Hints and my answers

  • con4i follows from modus ponens and an axiom.
  • For con4d, use syl with the given hypothesis as its first premise.
  • For pm2.21i, use con4i. The remaining goal just adds an antecedent to the hypothesis.
  • For pm2.24ii, use ax-mp with ph as its first premise. The other hypothesis lets you use the explosion rule we just proved.
  • For pm2.21d, use con4d. Keep ph as the shared antecedent while adding an antecedent inside it.
  • For pm2.21, use pm2.21d. Choose the shared antecedent to match the goal, then look carefully at the remaining premise.
  • For pm2.24, try commuting the two antecedents.
  • For pm2.18, use pm2.43i with ( -. ph -> ph ) as a single wff. The remaining goal fits con4d; keep that same shared antecedent as you work backwards.

4.1.5 Double negation and classical proof rules

Question 20. Prove double negation elimination and introduction.

metamath
$( Double negation elimination $)
notnotr $p |- ( -. -. ph -> ph ) $= ? $.

$( Double negation introduction $)
notnot $p |- ( ph -> -. -. ph ) $= ? $.
$( who's there? $)

$( Contraposition with a negated consequent: from ph -> -. ps, infer ps -> -. ph. $)
${
  con2i.a $e |- ( ph -> -. ps ) $.
  con2i $p |- ( ps -> -. ph ) $= ? $.
$}

$( Contraposition with a negated antecedent: from -. ph -> ps, infer -. ps -> ph. $)
${
  con1i.1 $e |- ( -. ph -> ps ) $.
  con1i $p |- ( -. ps -> ph ) $= ? $.
$}

$( Contraposition: from ph -> ps, infer -. ps -> -. ph. $)
${
  con3i.a $e |- ( ph -> ps ) $.
  con3i $p |- ( -. ps -> -. ph ) $= ? $.
$}

$( Modus tollens $)
${
  mto.1 $e |- -. ps $.
  mto.2 $e |- ( ph -> ps ) $.
  mto $p |- -. ph $= ? $.
$}

$( Proof by cases $)
${
  pm2.61i.1 $e |- ( ph -> ps ) $.
  pm2.61i.2 $e |- ( -. ph -> ps ) $.
  pm2.61i $p |- ps $= ? $.
$}

$( Reductio ad absurdum $)
${
  pm2.65i.1 $e |- ( ph -> ps ) $.
  pm2.65i.2 $e |- ( ph -> -. ps ) $.
  pm2.65i $p |- -. ph $= ? $.
$}

$( Peirce's law. Note that it seems to not use negation... but
   it's in the section with ax-3? How curious. $)
peirce $p |- ( ( ( ph -> ps ) -> ph ) -> ph ) $= ? $.

Hints and my answers

  • For notnotr, use syl with pm2.18 as its second premise. The other premise is an instance of explosion.
  • For notnot, use con4i. The remaining goal is a double negation theorem with a negated wff substituted for its variable.
  • For con2i and con1i, use con4i. A double negation appears in the remaining goal; use syl to connect it with the given hypothesis.
  • For con3i, try con2i. Double negation introduction will help with the remaining goal.
  • For mto, use ax-mp with the negated hypothesis as its first premise. The other premise needs contraposition.
  • For pm2.61i, use ax-mp with an instance of pm2.18 as its second premise. For the remaining goal, try syl; one of the given hypotheses needs contraposition.
  • For pm2.65i, use pm2.61i, splitting on ph. One case is an identity; in the other, try syl with the two conflicting hypotheses, using contraposition on one.
  • For peirce, use pm2.61i, splitting on ph. One case is an axiom instance; for the other, try syl with explosion as its first premise.

04.5 Other proof databases

The important comparison is what the same Metamath verifier does with very different statements and primitive rules. Keep these exercises in separate practice files: id, mpd, and even |- need not have the same role in different databases. The links go to the actual source databases; where only a small fragment is displayed, use that fragment as a new .mm file.

iset.mm: intuitionistic negation

iset.mm uses familiar wff, |-, ->, and -. notation, but begins its negation development with ax-in1 and ax-in2 rather than set.mm's ax-3:

metamath
ax-in1 $a |- ( ( ph -> -. ph ) -> -. ph ) $.
ax-in2 $a |- ( -. ph -> ( ph -> ps ) ) $.

Assume we have already proved id, and con2i, whose premise and conclusion are |- ( ph -> -. ps ) and |- ( ps -> -. ph ). Prove the actual notnot:

metamath
notnot $p |- ( ph -> -. -. ph ) $= ? $.

Hint: apply id to -. ph, then con2i. In this case, the same result holds in classical set.mm and intuitionistic iset.mm, although its proof need not use the same rules. The converse is a different question.

ql.mm: an equational language

The beginning of ql.mm is an equational system for ortholattices, with term variables and orthocomplement written '. Its first id proof uses this small fragment:

metamath
$c term wff |- ' = $.
$v a b c $.
wva $f term a $.
wvb $f term b $.
wvc $f term c $.
wn $a term a ' $.
wb $a wff a = b $.
ax-a1 $a |- a = a ' ' $.
${
  r1.1 $e |- a = b $.
  ax-r1 $a |- b = a $.
$}
${
  r2.1 $e |- a = b $.
  r2.2 $e |- b = c $.
  ax-r2 $a |- a = c $.
$}

id $p |- a = a $= ? $.

Hint: use double orthocomplementation, reverse that equation, and compose. The proof uses neither implication nor a propositional modus ponens rule.

hol.mm: explicit contexts

hol.mm uses simply typed terms. Statements look like |- R |= S, with an explicit context R. ( S , T ) combines context assumptions, and [ S ==> T ] is a term built using defined implication.

The actual early theorem syl2anc is (below, only its essential hypotheses and target are shown):

metamath
${
  syl2anc.1 $e |- R |= S $.
  syl2anc.2 $e |- R |= T $.
  syl2anc.3 $e |- ( S , T ) |= A $.
  syl2anc $p |- R |= A $= ? $.
$}

Use the primitive context-combination rule ax-jca and the primitive transitivity rule ax-syl. The point is to construct ( S , T ) in context R, then apply the third hypothesis. In the actual database there are type hypotheses and syntax declarations in addition to the excerpt above.

Now the particularly good example: modus ponens is itself a proved theorem in hol.mm. Its primitive inference mechanism includes equality transport (ax-eqmp); implication has been defined. The actual theorem is mpd (with its essential hypotheses shown, but not the earlier hol.mm declarations):

metamath
${
  mp.1 $e |- T : * $.
  mp.2 $e |- R |= S $.
  mp.3 $e |- R |= [ S ==> T ] $.
  mpd $p |- R |= T $= ? $.
$}

For this puzzle, use the preceding results imval, a1i, mpbi, mpbir, dfan2, and simprd. imval rewrites implication as an equality involving conjunction; mpbi/mpbir move along such equalities; dfan2 relates Boolean conjunction to context conjunction; simprd projects the right conjunct. Starting with the two premises, obtain R |= [ [ S /\ T ] = S ], then R |= [ S /\ T ], then R |= ( S , T ), and finally R |= T.

This is a puzzle about the actual rule dependencies, not a claim that one database has a special privilege to define what modus ponens 'really is'.

04.6 Optional: Meredith's single axiom

This is an advanced substitution puzzle, not a prerequisite to Chapter 05. The Metamath development of Meredith's axiom is unusually striking: using ->, -., and modus ponens, it connects one very large axiom schema with familiar sets of three schemas. The set.mm labels below are real labels; start from a separate small system where the Meredith schema is available, rather than using the earlier set.mm theorems to short-circuit the exercise.

Write M(a,b,c,d,e) for the schema

05 Metatheorems, notation, and history

Working notes and problems to revisit. This chapter is intentionally unfinished; sections need not yet form a continuous exposition.

Chapter 04 was mostly code, with the program Metamath as the foundation. It's difficult to talk about the history of logic without talking about things that are surprisingly distant from this bootstrapping, and that take much, much more effort to get to.

For these notes, our grounding is the 02 verifier and concrete proof files it accepts. We can also discuss ordinary mathematical arguments, proposed algorithms, and historical claims; none of those discussions is being presented as a verified Metamath proof. I mark such claims (to formalize). The eventual task is to represent syntax, derivations, and verification as data in a suitable Metamath database, and prove facts about them there. That is much later work, perhaps around Chapter 14. Mario Carneiro's formalizations and Metamath Zero are useful future references.

Three distinct achievements should not be conflated: (1) checking one particular proof; (2) writing a program that takes proofs as input and emits proofs as output; (3) proving inside a formal system that the program works for all valid inputs. We can pursue them in that order.

Object language and metalanguage

Logicians separate two levels. The object language is the formulas being studied; in Metamath, these are the strings inside statements. The metalanguage is the language used to talk about those formulas: English plus a few symbols. Statements such as "this $p verifies" or "no proof of |- M U exists" belong to the metalanguage. A large part of reading logic texts is noticing which level a symbol belongs to. We can eventually make the metalanguage itself a formal object language, by encoding formulas and proofs as data.

Notation

⊢ φ conventionally means "φ is a theorem." This is a statement about derivability, not a connective inside φ. Metamath's |- is just a constant at the front of an expression. A Metamath statement |- ph is distinct from a metalanguage claim about the existence of a proof of some formula; it is the object we ask the verifier to derive. We can later define an explicit Provable(code) predicate in another formal language.

Γ ⊢ φ means "φ is deducible from Γ," where Γ is a set of formulas. A $p with $e hypotheses gives an immediately useful analogue, though the correspondence depends on the chosen encoding of substitutions and hypotheses. Enderton uses Γ; α for adjoining an assumption to Γ.

Rule notation. A rule of inference is often drawn with its premises above a line and its conclusion below. Modus ponens:

  φ      φ → ψ
 ───────────────  MP
        ψ

This is the ax-mp block. A proof stacks rules like these into a tree. Metamath's RPN proof is that tree written out in postorder, which is what the stack in the 02 verifier evaluates.

Arrows. The connective → is set.mm's ->. Older books write it ⊃, and Mendelson writes it ⇒. Elsewhere ⇒ means something else entirely: the sequent arrow (see the sequent calculus section below), or just English "implies" in prose.

⊨. Conventional Γ ⊨ φ means that every valuation satisfying all of Γ also satisfies φ; ⊨ φ means that φ is valid under all valuations. To investigate this concretely, define valuations, evaluation of syntax, and then the satisfaction relation. Metamath can host those definitions; we have not yet constructed them. hol.mm uses the characters |= for something else: they are part of its actual assertions |- R |= S.

Book differences. Enderton's deductive calculus is in his first-order chapter, and its propositional part takes every tautology (and its generalizations) as an axiom. For a three-axiom Hilbert-style system like set.mm's, Mendelson's chapter 1 is the closer match.

More vocabulary

Schema vs. atom. In a textbook, a sentence symbol such as A₁ or p is one particular propositional variable of the object language, while α ranges over all formulas. set.mm has only the second kind. So every set.mm theorem is what a textbook calls a theorem schema. Some authors call these "metatheorems," a weaker sense of the word than the one below.

"Deduction." set.mm uses "inference" for a rule with bare hypotheses and "deduction form" (suffix d) for the shared-antecedent version. A logician's "deduction" is Enderton's: a finite sequence of formulas, each either in Γ, a logical axiom, or obtained by modus ponens from earlier ones. A Metamath proof with $e hypotheses gives a closely related schematic rule, but the exact correspondence depends on how the system, substitutions, and hypotheses are encoded. That correspondence is itself a useful question.

Derivable vs. admissible. A rule is called derivable when its conclusion can be derived from its premises in the chosen calculus; a $p with $e hypotheses is one convenient representation. It is admissible if every substitution of theorem premises also has a theorem conclusion. Derivability gives admissibility. Proving admissibility can require a claim about all derivations, which we have not formalized here.

Metatheorem: a mathematical result about a formal system, often quantifying over formulas or derivations. The deduction theorem, MIU nonderivability arguments, and cut elimination are examples. This is vocabulary to recognize, not a claim that such results are forever outside Metamath.

The MIU system

The MIU system is described in chapter 1 of Hofstadter's Gödel, Escher, Bach (GEB). miu.mm has good exposition. (Appendix D of the Metamath book, "The MIU system," is just a copy of it, so open miu.mm instead.) There's also a Lean project that states "The principal aim of this project is to give a Lean proof that the derivability of a string is a decidable predicate."

The deduction theorem

In Enderton's notation:

If Γ; α ⊢ β, then Γ ⊢ (α → β).

The usual informal argument is by induction on the deduction of β. Rewrite every line χ as α -> χ. There are three cases, and chapter 04 proved a tool for each:

  • the line is α itself: use id.
  • the line is an axiom, another hypothesis, or an earlier theorem: use a1i.
  • the line follows by modus ponens from earlier lines: use mpd.

For proofs using derived rules, one can expand them back to primitive rules, or arrange suitable deduction-form replacements. This motivates the many i/d variants in set.mm. Chapter 04 Question 14 used a particular replacement. The general correctness of the transformation is (to formalize).

The proposed proof methods have a useful common shape: reason over an arbitrary derivation. MIU's Q4 suggests an invariant preserved by the rules; the deduction theorem suggests a procedure transforming proof objects. Neither claim is itself one of the ordinary MIU or propositional $p statements written so far. Once derivations are represented as data in a richer database, both become candidates for explicit formalization. MIU has no implication connective in the language shown, so the usual implication-form version of the deduction theorem is not a statement in that particular language.

Predicate logic adds a complication. set.mm has the rule ax-gen: from |- ph, infer |- A. x ph. Applying the naive deduction theorem to it would give |- ( ph -> A. x ph ), which is false when ph is x = y. So with generalization, the theorem needs a side condition: you can't generalize on a variable that is free in the hypothesis being discharged. Propositional logic has no generalization rule, so this never came up in chapter 04.

Sequent calculus

A Hilbert-style system manipulates formulas, and assumptions live outside them, in the metalanguage. A sequent calculus (Gentzen, 1934) manipulates sequents, Γ ⇒ Δ, read as "if everything in Γ holds, then something in Δ holds." Some books write Γ ⊢ Δ instead. The assumptions are now part of the object language, so moving an assumption into an antecedent becomes an ordinary rule. Each connective has a left rule (how to use it) and a right rule (how to prove it). The right rule for → is

   Γ, φ ⇒ ψ, Δ
 ───────────────  →R
   Γ ⇒ φ → ψ, Δ

Propositional sequent calculus fits in Metamath with no $d:

A ctx is a list of wffs: c0 is the empty list, and cadd appends one wff. Every wff is a variable, starts with -., or is wrapped in parentheses, so a list of wffs can be split up only one way and needs no commas. G ph H means "a context with ph somewhere in it." Every rule acts at any position, so no reordering rule is needed.

ax-id is the axiom φ ⇒ φ with extra context. The other four rules are ¬L, ¬R, →L and →R. There are no structural rules (weakening, contraction, exchange); logicians call a system like this G3-style.

Here is ph ⇒ ph turned into ⇒ ( ph -> ph ). All four contexts are empty (c0), and the first wph wph gives the substitutions for ph and ps in ax-impr:

metamath
seqid $p |- => ( ph -> ph ) $=
  wph wph c0 c0 c0 c0 wph c0 c0 c0 c0 ax-id ax-impr $.

A context with two formulas, ph ps, has the syntax proof wps wph c0 cadd cadd. Matching a rule like G ph H => ... against a sequent can succeed in several ways (where does G end?), so a proof assistant may ask you to choose, as with miu.mm. By default mmj2 expects every |- statement to parse as a wff, so use metamath.exe or the 02 checker.

Cut elimination (Gentzen's Hauptsatz) says that every sequent derivable with ax-cut is derivable without it (to formalize). Like the deduction theorem, it transforms derivations. Three consequences, all (to formalize):

  • The subformula property. Every formula in a cut-free derivation is a piece of the final sequent. That's how seqmp can be admissible without being derivable. Taking modus ponens out of chapter 04's system, by contrast, would leave only axiom instances.
  • Consistency. No rule concludes the empty sequent |- =>, so it has no cut-free derivation. The sequent proofs of ax-1–ax-3, together with seqmp, translate chapter 04's theorems into sequents. If chapter 04's system proved both φ and -. φ, two cuts would give |- =>. This argument never mentions truth tables.
  • A decision procedure. Backward search always terminates, because every rule's premises have fewer connectives than its conclusion. A G3 prover in the SICP query language from 03, printing proofs that the 02 checker verifies, would be a good project.

For quantifiers, the ∀-right rule normally needs the proviso that x doesn't occur in the context. In Metamath that's a $d:

metamath
${
  $d x G $.  $d x H $.  $d x D $.  $d x E $.
  ax-allr.1 $e |- G H => D ph E $.
  ax-allr $a |- G H => D A. x ph E $.
$}

Without the $d, this rule would prove ph ⇒ ∀x ph, which is the ax-gen mistake from the deduction theorem section, in sequent form.

A note on hol.mm

hol.mm writes assumptions into its statements, as in |- R |= S, much like a sequent. There, modus ponens for ==> is a theorem (labeled mpd) proved from the definition of implication. The primitive rule is ax-eqmp, modus ponens for equality.

Threads to research

  • Gentzen's sequent calculus and cut elimination (1934).
  • Church's λ-calculus, Gödel–Herbrand recursive functions and Turing machines: different precise models of computability, related by formal translations. Study which equivalences were established as theorems, and which broader assertions are summarized by the Church–Turing thesis.
  • Curry–Howard: study explicit correspondences between selected proof calculi and typed program calculi, not a blanket identity of every notion of proof and program.
  • De Bruijn's Automath (from 1967), and the de Bruijn criterion: a small, independently understandable proof-checking component.
  • Mizar (1973), LCF (Milner, 1970s), and the Boyer–Moore prover. Shankar mechanically checked Gödel's incompleteness theorem in the Boyer–Moore prover in 1986.
  • Mario Carneiro: set.mm's developments about Metamath systems, and Metamath Zero. Find concrete statements, proof encodings, and verified translations to work through.
  • Why logic texts state metatheory in English. Mechanization had real historical costs; the traditional mathematical treatment is also an intentional and useful research convention. This project chooses a more operational starting point.
  • A useful primary-source example: the introduction to Solovay's Peano arithmetic peano.mm explicitly separates formal Metamath statements from informal metamathematical arguments and observes that those arguments could be formalized in primitive recursive arithmetic. The source even identifies semantic justification of some axioms as work left to the reader. This is an unusually direct historical example of the distinction these notes are tracking.
