5.0.1 Variables in which language?

There is an easy way to get confused before we've even started: the word "variable" is doing several jobs. In an ordinary first-order formula, a variable can occur as an argument of a predicate or be bound by a quantifier. In a textbook's discussion of those formulas, a metavariable can stand for a whole formula. Metamath then has its own declared variables and type hypotheses. I want to keep track of which of these we're discussing, instead of relying on the typography to tell us.

Source 1. The Metamath book, especially §1.4.5, "Metamath and First-Order Logic," and §4.2.4, "The $d Statement." The latter starts on printed page 120. The important point for our purposes is that the verifier does not have a primitive free-variable or bound-variable test. Its substitution mechanism and $d conditions are used by an axiom system to control the substitutions that are permitted.

For example, ph has type wff in our familiar database, while x has type setvar in the predicate-calculus portion of set.mm. Both are Metamath variables. An instance of ph may be a large formula containing several setvar variables; an instance of x must satisfy its own syntax hypothesis. The declaration vx $f setvar x $. belongs to the syntax machinery. It is not itself a quantified assertion about a mathematical set.

This also explains why a condition involving x and ph can make sense. We are restricting which replacements for two Metamath variables can be used together. The Proof Explorer's discussion of axioms, schemes, and distinct metavariables is useful to read alongside the book here.

Consider the familiar formula

The occurrence of x on the left is free, while the occurrence of x inside the quantified equality is bound. The quantifier does not reach back across the implication. This is why it is useful to talk about occurrences: one written variable name can have different roles in different parts of a formula.

A substitution can change these roles if we're careless. For example, consider replacing the free x in

5.0.4 What $d asks the checker to do

The exact rule in §4.2.4 of the book has two parts. When applying an assertion with a required disjoint pair, the two replacement expressions must have no Metamath variables in common. Also, every pair consisting of one variable from each replacement must be covered by the active disjoint conditions in the proof. The second part is how the restriction is inherited.

For a small example, suppose an assertion requires $d ph ps $., and consider the replacements ph by x = y and ps by z = w. The variables occurring in the two replacements are disjoint as written. The proof still needs the cross-pairs x,z, x,w, y,z, and y,w. It does not acquire a requirement that x and y be distinct from each other from this particular $d pair. We're checking pairs across the two replacements.

If instead both replacements contain y, there is an immediate conflict. Declaring extra pairs cannot repair that overlap. On the other hand, identical replacements containing only constants do not conflict with this particular test, because they contain no variables. Their syntax hypotheses still have to be satisfied, of course. These are checks on substitution data, so we can practice them before making a large predicate-calculus proof.

The discussion attached to 19.21v also gives a useful terminology distinction: "does not occur" is stronger than "is not free in." For instance, x is not free in A. x x = x, but it certainly occurs there. That formula therefore cannot be used as the replacement for ph in a direct application of ax-5 with x as the bound variable. There are other theorems for less restrictive situations.

5.4 Quiz Questions

These questions are meant to test the terminology and the mechanics that the proof exercises use. The answers below are short sketches to revise after working through the chapter.

Question 1

In ( x = y -> A. x x = y ), which occurrences of x and y are free, and which are bound? Why is it more precise to ask about occurrences than simply to classify each variable name as free or bound?

Answer sketch

The x in the left equality is free, and the x in the right equality is bound by A. x; the x written immediately after A. names the binder. Both equality occurrences of y are free. A single name can occur in different scopes; the binding depends on the occurrence's location.

Question 2

An assertion requires $d ph ps $.. We replace ph by x = y and ps by z = w. Which inherited pairs are needed? Why isn't the fact that these are four differently written letters enough?

Answer sketch

The cross-pairs are x,z, x,w, y,z, and y,w. The checker needs the corresponding active restrictions. The distinct spellings by themselves do not record which later substitutions the assertion permits.

Question 3

Explain why $d x y $. is different from |- -. x = y. Also explain why $d x ph $. is stronger than saying that x is not free in the formula.

Answer sketch

The first is a restriction on substitutions for Metamath variables; the second is a mathematical assertion of inequality. For the formula case, nonoccurrence excludes bound occurrences too. A. x x = x is a concrete example in which x occurs but is not free.

Question 4

What is variable capture? Describe what goes wrong with the naive replacement of free x by y in A. y x = y, and explain the role that changing the bound name can play in avoiding it.

Answer sketch

The inserted y falls within the scope of the existing A. y binder and becomes bound. A suitable change to a fresh bound name can preserve the role of the inserted occurrence. The admissibility of the change must be handled by the chosen syntax rules or, in our exercises, by an appropriate theorem.

Question 5

What is the historical connection between Tarski's work and Metamath's distinct-variable approach? Name the source used for the dates.

Answer sketch

The Proof Explorer's history credits Tarski with stating the approach in 1951 and publishing proofs in 1965. The relevant idea is organizing an axiomatization using distinct-variable conditions rather than requiring the usual free-variable and proper-substitution machinery as primitive notions.

Question 6

Compare ax-gen with ax-5. Why can't we simply turn the former into an unrestricted theorem |- ( ph -> A. x ph )?

Answer sketch

ax-gen takes an established assertion as a premise and universally quantifies it. The closed implication has a different logical claim. ax-5 supplies that implication under a disjoint-variable restriction, and the ax-gen commentary explicitly warns that its unrestricted closed form need not hold.

Question 7

Which tool would you look for if you had proved ph <-> ps and wanted A. x ph <-> A. x ps? What changes if you instead have ph -> ps and want ph -> A. x ps?

Answer sketch

The first is the pattern of albii. The second is the pattern of alrimiv, whose disjointness condition constrains ph and x. In the first case both sides are quantified; in the second the antecedent remains outside.

Question 8

In the rename-equality exercise, why do we need to protect z as well as distinguish x and y? What would a general theorem about alpha-renaming say beyond this particular checked equivalence?

Answer sketch

Substituting the two equality formulas into cbvalvw produces the additional pairs x,z and y,z. A general theorem about a specified renaming procedure would quantify over represented expressions and the procedure's inputs or outputs. This exercise supplies one checked instance using an existing rule.

What to take away

Read this as a demonstration of how much arithmetic can be done with recursive functions, recursive predicates, and induction. Skolem starts with addition and gets as far as gcd, lcm, prime factorization, infinitely many primes, and finite counting. He is developing arithmetic under a restriction on the kinds of statements he uses. He is not proving that quantifiers can be removed from any arithmetic theory we might write down.

The restriction is on unbounded bound variables. Free variables are welcome: $a+b=b+a$𝑎+𝑏=𝑏+𝑎 is one of his “functional assertions.” So our use of arbitrary terms in theorem schemes is close to what he has in mind. He does not require us to replace every theorem by a separate theorem about each numeral. Also, “quantifier-free” does not mean “predicate-free”: much of the paper consists of introducing predicates and proving things about them.

The editorial introduction explicitly says that this is not a fully specified formal system. Skolem takes arithmetic reasoning and substitution of equals for equals for granted. In arith.mm, those steps need actual rules and proofs. That is part of our project, rather than something this paper has already specified for us.

A short route through the paper

  1. Read the introduction and Skolem's opening, pp. 1–4. Separate the editor's explanation of later primitive recursive arithmetic from Skolem's own claims. The main question is how to replace a search over all numbers by a bounded computation. You can skim the discussion of “the author of Waverley.”

  2. Read §1, pp. 4–5 carefully. His first theorem is associativity of addition, followed by the lemma $a+1=1+a$𝑎+1=1+𝑎, then commutativity.   3. Read Definition 2 at the start of §2, p. 5, then skim the order proofs.   4. Read the opening of §4, pp. 9–11: Definitions 5–6 and the discussion after Theorem 20. This is the most useful part for our question about quantifiers. It explains both how to define divisibility by recursion and why proving a theorem about that predicate requires more than manipulating equations with supplied witnesses.

How to prove that no proof exists

Suppose someone supplies a proof of |- ( A. x ph -> ph ) using the E1 file. Every $p it cites can be expanded into its own proof. Use the truth-table calculations from propositional logic. Give each wff variable a value T or F, and evaluate the connectives by their usual truth tables. Extend that calculation with two deliberately simple instructions:

  • An expression beginning with A. x gets T, whatever follows it.
  • An expression beginning with E. x gets F, whatever follows it.

This is a calculation on the expressions in a proposed proof. The claim to check is: whenever its essential hypotheses evaluate to T, every assertion application with a |- conclusion also evaluates to T. The wff and setvar steps supply expressions of the required types; they do not assert that those expressions evaluate to T. Countermodels: which additions actually matter?

E2 used a single T/F value per expression. For stronger files, we can use several values per expression, indexed by numbered positions. Evaluate the propositional connectives separately at each position. Draw arrows between the positions, then evaluate A. x ph at position w as T exactly when ph evaluates to T at every position with an arrow from w. Evaluate E. x ph as T when at least one of those positions gives ph value T. With no outgoing arrows, these instructions give T and F respectively, recovering E2's calculation. Use single arrows, not paths of several arrows.

The invariant is now: every |- conclusion evaluates to T at every position, whenever its essential hypotheses do. Check it against the same assertions. ax-4 passes because at each arrow's destination, ph -> ps and ph give ps. ax-gen passes because an expression that is T at every position is T at every destination. ax-mp and the propositional assertions pass position by position, and df-ex passes by the two evaluation rules. These checks work for arbitrary substituted wffs. A proposed theorem that evaluates to F at even one position therefore cannot have an E1 proof.

To extend the argument to a larger file, check its additional $a assertions too. For example, sp passes all assignments if every position has an arrow to itself: A. x ph then tests ph at that position as well. To use the invariant for proofs with $e hypotheses, those hypotheses must evaluate to T at every position. T at just the position where the target fails does not suffice for the ax-gen check.

This construction is called a Kripke model. Its positions are usually called worlds, the arrows form an accessibility relation, and the positions and arrows together form a frame. Assigning the initial T/F values to wff variables is a valuation. “World” here names a position in the evaluation; the proof argument only uses the calculation just given. See the soundness connection between models and proofs.

The system names specify which additional assertions must pass:

  • K is the E1 system, valid on arbitrary frames.
  • KD adds D and uses serial frames: every world sees at least one world.
  • KT, also called T, adds T and uses reflexive frames: every world sees itself.
  • S4 adds T and 4 to K. Its frames are reflexive and transitive: if w sees v and v sees u, then w sees u.
  • S5 adds T and 5 to K. Its frames are equivalence relations: reflexive, symmetric, and transitive. They split into groups within which every world sees every world, with no arrows between groups. From any starting world, the calculation therefore tests every position in that group.

These are the usual frame conditions for the modal systems. More axioms restrict the permitted frames. To disprove derivability in S4, for example, we must use a reflexive, transitive frame; an arbitrary K countermodel would not suffice.

E6 Quantifier shift (set.mm)

Warning

This section is AI-generated and has not been reviewed.

Here the order of different quantifiers matters. E. x A. y ph chooses one x that works for every y. In A. y E. x ph, the choice of x may depend on y. Thus “someone is everyone's mother” implies “everyone has a mother,” while the reverse implication would demand a single mother for everyone. Two universal quantifiers can commute, as can two existential quantifiers; the mixed case is different. Reprove these in set.mm:

metamath
19.12 $p |- ( E. x A. y ph -> A. y E. x ph ) $= ? $.
alcom $p |- ( A. x A. y ph <-> A. y A. x ph ) $= ? $.
excom $p |- ( E. x E. y ph <-> E. y E. x ph ) $= ? $.
excomim $p |- ( E. x E. y ph -> E. y E. x ph ) $= ? $.

For a concrete counterexample to the converse, use ph := y = x on a two-element domain. Every y equals some x (choose x = y), but no single x equals both elements. This proves that the converse is not a theorem of pure first-order logic. It does not make its negation a logical theorem: on a one-element domain the converse is true.

In set.mm we can go further, using set theory to establish that there are at least two objects. The next exercise proves the negation of this particular instance of the converse:

There is a second kind of “unprovability” to distinguish from E2. A textbook may prove by induction on formulas that every concrete instance of a pattern is derivable. For example, it treats atomic formulas, then shows how to extend the result through negations, implications, and quantifiers. This is a metatheorem: a recipe for constructing proofs, potentially with a different proof for each formula.

A Metamath theorem with ph in it asks for one finite proof that works directly for an arbitrary wff substituted for ph. Metamath's substitution mechanism does not itself inspect the structure of ph or perform that induction. Consequently, “every concrete instance has a proof” and “this scheme has a single Metamath proof from these schemes” are different claims.

That distinction explains the auxiliary predicate-calculus axioms. E8 Capstone: cylindric algebra axioms (set.mm)

Warning

This section is AI-generated and has not been reviewed.

Cylindric algebras express quantifier laws as algebraic identities. Think of a formula as the set of assignments that make it true. Conjunction becomes intersection, negation becomes complement, and implication corresponds to inclusion. Existential quantification c_x enlarges a set of assignments: an assignment belongs to c_x a if changing just its x value can make it belong to a. The name “cylindric” comes from letting that coordinate vary freely, as when extending a region into a cylinder.

Write 0 for false, 1 for true, a · b for conjunction, -a for negation, and a <= b for implication. Algebraic equality here means logical equivalence. The element d_xy represents the formula x = y.

The seven laws below are exercises labeled C1–C7 locally; the labels should not be assumed to match a particular textbook's axiom numbering. For the algebraic theory, the reference is Henkin, Monk, and Tarski, Cylindric Algebras (1971).

  • C1: c_x 0 = 0. Quantifying an impossible condition cannot produce a witness. Prove -. E. x F..
  • C2: a <= c_x a. The current value of x supplies a witness whenever a holds. Find ( ph -> E. x ph ).
  • C3: c_x (a · c_x b) = c_x a · c_x b. The statement “some x satisfies b” no longer depends on the current x, so it can be taken outside another existential quantifier over x. Prove ( E. x ( ph /\ E. x ps ) <-> ( E. x ph /\ E. x ps ) ).
  • C4: c_x c_y a = c_y c_x a. Two existential quantifiers commute. Find ( E. x E. y ph <-> E. y E. x ph ).
  • C5: c_x d_xy = 1. There is an x equal to y. Find E. x x = y.
  • C6: d_xy = c_z (d_xz · d_zy), with z distinct from x and y. Two objects are equal exactly when some object equals both. Prove ( x = y <-> E. z ( x = z /\ z = y ) ).
  • C7: c_x (d_xy · a) · c_x (d_xy · -a) = 0, with distinct variable names x and y. Fixing x equal to y cannot make a both true and false. Prove -. ( E. x ( x = y /\ ph ) /\ E. x ( x = y /\ -. ph ) ). Distinct variable names do not require distinct values.
